### ❤️My coding journey

My interest in programming started with video games. I spent a lot of time creating and modifying maps in the Warcraft 3 World Editor, which led me to explore C++ and understand how systems and logic work behind the scenes.

Since then, I’ve continuously built personal projects and developed solutions for friends and family, turning ideas into working applications. Parallel to this, I’ve been studying Systems Engineering, combining academic knowledge with practical experience.

I work on both frontend and backend, using technologies like HTML, CSS, JavaScript, React, PHP and MySQL. I enjoy building complete applications, from the interface to the database and server logic.

Today, I’m focused on creating software that feels smooth to users and stays maintainable for developers. I value clean architecture, measurable performance, and codebases that can grow without friction.
